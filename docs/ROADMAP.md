# Roadmap

## M0 — Foundations
- [ ] CMake + NDK build, Android app shell, JNI bridge
- [ ] Core: math, allocators, job system, logging
- [ ] Vulkan bootstrap with GLES fallback, clear-screen on device

## M1 — 2D engine
- [ ] ECS + transforms + serialization
- [ ] Sprite batcher, cameras, tilemaps
- [ ] physics2d: shapes, broadphase, solver, collision events

## M2 — Editor v1
- [ ] Hierarchy, inspector, touch gizmos, undo/redo
- [ ] Play-in-editor, save/load projects

## M3 — 3D engine
- [ ] Mesh/material pipeline, forward+ lighting, shadows
- [ ] physics3d: GJK/EPA, BVH, solver, sleeping

## M4 — AI creation
- [ ] Prompt -> scene/entity/script edits with validation and undo
- [ ] AI-assisted asset generation

## M5 — Ship it
- [ ] Export games as APK/AAB
- [ ] Performance budget tooling (frame time, thermals, memory)
